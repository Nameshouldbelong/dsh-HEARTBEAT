## 判定逻辑终态

- `hit`：2xx + cache_read>0（healthy，计数清零）
- `recreated`：2xx + read=0 + creation>0（healthy，计数清零）
- `no-cache`：2xx 读写皆 0 → 计 cache 失败，连续 3 次 stale
- `error`（timeout/ECONNRESET/429/5xx）→ retry +2min/+4min，不计 cache 失败；耗尽 → stale
